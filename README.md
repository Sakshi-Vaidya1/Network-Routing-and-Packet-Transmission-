# 🌐 Network Routing and Packet Transmission Using Shortest Path Algorithm

## 📌 About the Project

This project is a web-based **Network Routing Visualizer** that demonstrates how data packets travel through a network using the shortest path algorithm.

It allows users to create a network of routers, assign connection costs, select a source and destination, and visualize the shortest route between them. The project uses **Dijkstra's Algorithm** to calculate the minimum-cost path.

## 🎯 Objectives

- Understand the working of network routing.
- Find the shortest path between two routers.
- Visualize router connections and transmission costs.
- Simulate packet movement through the selected route.
- Learn how graph algorithms are applied in computer networks.

## ✨ Features

- **Interactive Network Topology:** Visualize routers and their connections.
- **Custom Router Configuration:** Adjust the number of routers.
- **Connection Management:** Add or remove links between routers and set their costs.
- **Shortest Path Calculation:** Find the minimum-cost route using Dijkstra's Algorithm.
- **Packet Transmission Simulation:** Animate a packet moving along the calculated route.
- **Step-by-Step Visualization:** Observe the packet's progress through the network.
- **Route Information:** View the selected path and its total cost.
- **Activity Log:** Track routing and simulation activities.
- **Sample Network:** Load an example network to explore the project.

## 🛠️ Technologies Used

- **HTML5** – Structure of the web application.
- **CSS3** – Styling, layout, and animations.
- **JavaScript** – Network interactions and shortest-path calculation.
- **Dijkstra's Algorithm** – Minimum-cost pathfinding.

## ⚙️ How It Works

1. Create or load a network of routers.
2. Connect routers by specifying the cost of each link.
3. Select the source router and destination router.
4. Click the button to calculate the shortest path.
5. View the calculated route and total cost.
6. Start the packet transmission simulation to observe the packet moving through the selected routers.

## 🧠 Algorithm Used

**Dijkstra's Shortest Path Algorithm**

Dijkstra's Algorithm finds the minimum-cost path from a source vertex to other vertices in a weighted graph with non-negative edge weights.

In this project:
- Routers represent vertices.
- Network connections represent edges.
- Connection costs represent edge weights.
- The shortest path represents the minimum-cost route for packet transmission.
